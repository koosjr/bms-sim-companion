How it works: Each row in the table = one field the simulator needs. You click a column pill to assign it. For the address row, the 0-base / 1-base toggle sits right next to it — select your column, flip the toggle if needed. "stored as-is" or "−1 applied" shown immediately so there's no ambiguity. Optional fields (scale, access) can be skipped — the importer uses defaults.
