Address Base — Revised Behaviour

Display address = what the engineer sees (matches the manual). Stored/exported = always 0-based. They can differ — that's the point.

The rule
stored Always 0-based. This is what the simulator
and ThingsBoard JSON receive.
display Shown in the UI. Matches the supplier's manual
so engineers can cross-reference easily.
What the toggle does
Toggle = 0 (source is already 0-based)
display = stored = raw value
Toggle = 1 (source is 1-based)
stored = raw − 1
display = stored + 1  (= raw, what manual shows)

This also carries through to the Map Points tab. When you load an assembly into a device, the Map Points table shows both columns — Display for cross-referencing the manual, Stored for what gets exported. Engineers can verify addresses without mental arithmetic.
