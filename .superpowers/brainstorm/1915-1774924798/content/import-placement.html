Replace Step 1 with dual entry

Step 1 gains two tabs: "From BMSHub" and "From Supplier File". Supplier import creates the same data structure as a BMSHub import. Rest of the workflow is unchanged — device setup, point mapping, sim values all work exactly as today.

Add points inside Device Setup (Step 2)

Keep Step 1 for BMSHub imports. Add a "Load points from file…" button per device in Step 2. The supplier file populates that device's point list, including register addresses and BACnet instances already filled in. Great for mixing device sources in one project.

Standalone converter tool (separate page)

Add a dedicated "Import Supplier File" utility outside the main workflow. It converts CSV/XLSX → a BMSHub-compatible JSON that you then import via Step 1. No changes to existing steps — BMSHub JSON stays the canonical format. Best if you want a reusable converter for team use.
